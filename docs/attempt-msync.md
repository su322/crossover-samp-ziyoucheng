# 附录 I：msync 试验（2026-11-01 22:46，结论作废）

> 原 README 附录 I · 拆分于 2026-11-01 · [← 返回正文](../README.md)

把 `WINEMSYNC` 从 `1` 改成 `0` 之后，SA-MP 服务器浏览器里的**在线人数显示不正确**。

当时的推断是：关掉 msync 后 Wine 的同步等待退回 `wineserver` 往返，延迟变大，SA-MP 查询线程读到未写回的数据。

> **⚠️ 这个推断是错的，见附录 J。** 真正原因是服务器域名做了轮询解析，每次连到的节点不一样，人数自然不一样。msync 只是背了锅。

当前已恢复：

```
"CX_GRAPHICS_BACKEND" = "d3dmetal"
"WINEMSYNC" = "1"
```
